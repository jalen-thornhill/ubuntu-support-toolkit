# Ubuntu Support Toolkit

A Bash-based Linux support toolkit demonstrating safe automation, diagnostics, testing, and support documentation.

## Project purpose

Build six small Linux support commands that demonstrate practical diagnosis, safe automation, testing, documentation, and clear support communication.

## Intended users

This toolkit is designed for junior Linux support technicians, students developing UNIX skills, and employers reviewing entry-level systems-support work.

## Problems addressed

The project covers payroll reporting, controlled text transformation, process monitoring, user and system auditing, safe file backup and merging, and file-security auditing.

## Toolkit commands

- `payroll-report`
- `text-transform`
- `process-watch`
- `user-audit`
- `safe-merge`
- `file-audit`

## Scope

The public portfolio implementation uses Bash, with AWK and sed where appropriate. Each command will include documented usage, meaningful exit statuses, automated tests, and a support case.

## Exclusions

This repository is not the original COMP1215 coursework submission. It will not reproduce the assessed C shell solution or claim that the Bash implementation satisfies the original submission format.

## Assignment attribution

The project is inspired by six problems from a COMP1215 UNIX assignment. The original coursework requires C shell syntax; this separate portfolio project applies the same underlying business rules using Bash, AWK, and sed.

## Planned evidence

The completed repository will contain six commands, shared safe CLI behavior, automated tests, ShellCheck and formatting checks, architecture notes, learning-journal entries, and documented support cases. The planned final release is `v1.0.0`.
